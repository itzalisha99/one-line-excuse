## The line

> I outsourced your deadline to a subagent. It outsourced it to another. We are now a pyramid scheme with no bottom.

## How it works

`main.py` (Python standard library only, no dependencies) writes that single
line to `/output/entry.txt`. It is deterministic: every run produces the exact
same 114-character line. A `validate()` gate check mirrors the bounty gate
(1–160 characters, UTF-8, not only whitespace) before writing.

Run it with:

```sh
python3 main.py
```
